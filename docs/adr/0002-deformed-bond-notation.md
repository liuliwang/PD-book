# ADR 0002: 变形后键矢量的三种记号及其层级

专著中变形后键矢量存在三种等价记号：2.2.1 节以单键视角写 ξ+η = y(x',t) − y(x,t)（式 eq:deformed-bond），2.4.2 节以态记号写 Y̲⟨ξ⟩ = y(x+ξ,t) − y(x,t)（式 eq:state-deformation-ch02），符号表以缩写 y' − y 表示。三者数学等价（x' = x + ξ），记号差异源自表述层级：x' 是 ch02 全章的基本端点记号，x+ξ 显式表示键矢量（态的自变量是 ξ）。本 ADR 记录保留三种记号并存的决定，防止后续修订将有意选择当作疏漏统一掉。

## Decision: 三种记号保留并存，补等价式衔接

三种记号保留现状用词：ch02 继续以 x' 为基本端点记号（40+ 处，含对力函数、近场域、运动方程、守恒律等定义），2.4.2 节维持以 x+ξ 显式键矢量定义态，符号表维持缩写 y' − y。为消除读者困惑，在 2.4.2 节式 eq:state-deformation-ch02 之后补一句等价式衔接（由 x' = x + ξ 说明与式 eq:deformed-bond 等价），并将符号表 L55 的变形态条目扩充为完整等价式 Y̲⟨ξ⟩ = ξ + η = y(x+ξ,t) − y(x,t)。

理由：x' 与 x+ξ 分属键基/态基两种表述体系——x' 服务于单键与积分表述（键的另一端），x+ξ 服务于态定义（自变量为键矢量）。统一替换 x' 为 x+ξ 将破坏 ch02 已建立的概念层级，且需逐处审阅 40+ 处语境；反之亦然。这与 ADR 0001 Decision ②（F_x/H_x 并存）同理：记号并存是有意设计，衔接句与符号表扩充是成本最低的消除歧义手段。

## Consequences

- 后续修订 ch02 时，不应将 x' 统一替换为 x+ξ，也不应反向替换
- 新增章节引入变形后键矢量时，参照相邻章节记号（键基语境用 x'，态语境用 x+ξ）
- 若未来统一符号表，应以完整等价式 Y̲⟨ξ⟩ = ξ + η = y(x+ξ,t) − y(x,t) 为基准
